<h2><strong>In-Depth Breakdown of JN0-364 Exam Objectives</strong></h2>

<p><strong>1. Protocol-Independent Routing</strong></p>

<p>This section evaluates your understanding of routing fundamentals that apply across multiple protocols, including routing tables, route preferences, and forwarding behavior in Junos OS.</p>

<p><strong>2. Open Shortest Path First (OSPF)</strong></p>

<p>You must understand OSPF concepts such as areas, LSAs, adjacency formation, metrics, and basic OSPF configuration and troubleshooting on Juniper devices.</p>

<p><strong>3. Intermediate System to Intermediate System (IS-IS)</strong></p>

<p>IS-IS is heavily used in service provider environments. The exam covers IS-IS levels, metrics, TLVs, and operational behavior within Junos-based networks.</p>

<p><strong>4. Border Gateway Protocol (BGP)</strong></p>

<p>BGP is a core focus of JNCIS-SP. Topics include BGP attributes, route selection, peering types (iBGP and eBGP), and basic policy control for service provider routing.</p>

<p><strong>5. Layer 2 Bridging and VLANs</strong></p>

<p>This objective tests your knowledge of Ethernet switching, VLAN tagging, bridging domains, and Layer 2 forwarding behavior on Juniper platforms.</p>

<p><strong>6. Spanning Tree Protocols</strong></p>

<p>You are expected to understand STP fundamentals, including loop prevention, port roles, and how spanning-tree technologies operate in service provider and enterprise edge scenarios.</p>

<p><strong>7. Multiprotocol Label Switching (MPLS)</strong></p>

<p>MPLS is a critical component of service provider networks. The exam includes MPLS fundamentals, label operations, LSP concepts, and basic MPLS configuration awareness.</p>

<p><strong>8. IPv6</strong></p>

<p>This section covers IPv6 addressing, neighbor discovery, routing protocol support, and dual-stack deployment considerations in service provider environments.</p>

<p><strong>9. Tunnels</strong></p>

<p>You should be familiar with tunneling concepts such as GRE and IP tunnels, including their purpose and basic configuration use cases.</p>

<p><strong>10. High Availability</strong></p>

<p>High availability topics include redundancy concepts, graceful routing, and platform-level features that help maintain network stability and uptime.</p>
